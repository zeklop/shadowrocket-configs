# Shadowrocket: готовый конфиг для России

**Shadowrocket — это прокси-клиент для iOS**, который направляет трафик по правилам: одни сайты идут напрямую, другие через ваш прокси. Этот репозиторий — готовая конфигурация для России: российские сайты открываются напрямую, всё остальное идёт через ваш прокси, реклама и трекеры блокируются.

Конфиг обновляется автоматически раз в час, поэтому новые правила приезжают без переустановки.

## Как настроить Shadowrocket в России

Добавьте своё подключение в Shadowrocket и включите его, затем вставьте ссылку на конфиг во вкладке **Config** и нажмите **Use Config**. Настраивать группы прокси не нужно — достаточно одного любого подключения. Понадобится свой прокси или VPN-сервер, о нём ниже.

1. Добавьте своё подключение в Shadowrocket и включите его.
2. Откройте вкладку **Config** → **Add Config** и вставьте ссылку:

   ```
   https://raw.githubusercontent.com/zeklop/shadowrocket-configs/main/simple.conf
   ```

3. Нажмите на скачанный конфиг → **Use Config**.

## Что делает конфиг

| Трафик | Куда идёт |
|---|---|
| Российские сайты — зона `.ru` и список `RUSSIA.list` | напрямую, мимо прокси |
| Реклама и трекеры из `REJECT.list` | блокируются, не загружаются вообще |
| Всё остальное | через включённое у вас подключение |

Маршрутизация идёт только по доменам. Каждая строка `simple.conf` подписана комментарием — файл можно читать и править под себя.

## Списки правил

| Файл | Что внутри |
|------|------------|
| `REJECT.list` | рекламные и следящие домены, блокируются |
| `RUSSIA.list` | российские сайты вне зоны `.ru` — VK, Ozon, Авито, 2ГИС — идут напрямую |
| `NORU.list` | домены под отдельный прокси, используется только в `template.conf` |
| `AI.list` | AI-сервисы: ChatGPT, Claude, Gemini, Cursor. Только в `template.conf` |
| `YOUTUBE.list` | всё, что нужно для видео YouTube. Только в `template.conf` |
| `GOOGLE.list` | заготовка под отдельный прокси для Google. Пока не подключён ни к одному конфигу |

Строка с `#` в начале — выключенное правило. Так можно временно отключить домен, не удаляя его.

## Чем simple.conf отличается от template.conf

`simple.conf` рассчитан на одно подключение и не требует настройки групп. `template.conf` добавляет группы прокси, чтобы разные сервисы выходили через разные страны.

| | `simple.conf` | `template.conf` |
|---|---|---|
| Групп прокси | нет | `NL`, `US`, `RU` |
| Подключений нужно | одно | по числу групп |
| Комментарии в файле | на каждой строке | нет |
| Кому | начинающим | тем, кто хочет разделить трафик |
| Ссылка | [добавить](https://raw.githubusercontent.com/zeklop/shadowrocket-configs/main/simple.conf) | [добавить](https://raw.githubusercontent.com/zeklop/shadowrocket-configs/main/template.conf) |

В [`template.conf`](https://raw.githubusercontent.com/zeklop/shadowrocket-configs/main/template.conf) `NORU.list` и `YOUTUBE.list` идут через NL, `AI.list` — через US. Имена ваших подключений в Shadowrocket должны совпадать с именами групп: `NL`, `US`, `RU`.

## Частые вопросы

### Сколько стоит Shadowrocket и как его купить в России?

Shadowrocket — платное приложение, в [App Store](https://apps.apple.com/ru/app/shadowrocket/id932747118) оно стоит 249 ₽. Российские карты App Store не принимает с 2022 года, поэтому понадобится Apple ID другого региона и подарочная карта того же региона. Подписки внутри приложения нет — платите один раз.

### Почему iOS просит добавить VPN-профиль?

Shadowrocket пропускает трафик через системный VPN-профиль — иначе iOS не даст приложению видеть трафик других программ. При первом запуске система попросит разрешение и код-пароль устройства. Это штатное поведение, так работает любой подобный клиент.

### Как проверить, что конфиг работает?

Включите подключение и откройте любой российский сайт и любой зарубежный. Оба должны открыться. Что именно происходит с трафиком, видно в журнале соединений: там показано, какое правило сработало и куда ушёл запрос — напрямую или через прокси.

### Как обновить правила вручную?

Обычно не нужно: конфиг сам обновляется раз в час, это задано в нём самом. Если правки нужны немедленно, удалите конфиг и добавьте его заново по той же ссылке.

### Почему не работают звонки в Telegram и WhatsApp?

Звонки — это UDP-поток на релей-серверы, причём по IP, а не по домену, поэтому доменные правила его не ловят: он попадает под `FINAL,PROXY` и уходит в ваш прокси. Заработают звонки или нет, зависит от того, прокидывает ли UDP ваш сервер.

Что проверить:

- **Shadowrocket → Settings → UDP → Enable relay** должен быть включён.
- **Протокол.** С UDP стабильно работают Trojan, WireGuard/Amnezia и Shadowsocks с включённым на сервере UDP. У VLESS + Reality это [известная проблема](https://github.com/MHSanaei/3x-ui/issues/3283) — звонки не проходят даже когда UDP включён в настройках inbound.

## English

Ready-to-use **Shadowrocket configuration for Russia**. Russian sites go direct, everything else goes through your own proxy, ads and trackers are blocked. Add the config URL in Shadowrocket → **Config** → **Add Config**:

```
https://raw.githubusercontent.com/zeklop/shadowrocket-configs/main/simple.conf
```

`simple.conf` needs no proxy groups — one connection is enough. `template.conf` adds `NL` / `US` / `RU` groups to split traffic by country. Rules update automatically every hour.
