# shadowrocket-configs

Готовые конфигурации Shadowrocket для России. Российские сайты идут напрямую, всё остальное — через ваш прокси, реклама и трекеры блокируются.

## Быстрый старт

Понадобится приложение Shadowrocket и свой прокси или VPN-сервер (где взять — в конце).

1. Добавьте своё подключение в Shadowrocket и включите его.
2. Вкладка **Config** → **Add Config** → вставьте ссылку:

   ```
   https://raw.githubusercontent.com/zeklop/shadowrocket-configs/main/simple.conf
   ```

3. Нажмите на скачанный конфиг → **Use Config**.

Готово. Настраивать группы не нужно, конфиг сам обновляется раз в час.

## Что делает simple.conf

- Российские сайты — зона `.ru` и список `RUSSIA.list` — напрямую, мимо прокси.
- Реклама и трекеры из `REJECT.list` блокируются.
- Всё остальное идёт через включённое у вас подключение.

Каждая строка конфига подписана комментарием — его можно читать и править под себя.

## Списки правил

| Файл | Что внутри |
|------|------------|
| `REJECT.list` | рекламные и следящие домены, блокируются |
| `RUSSIA.list` | российские сайты вне зоны `.ru` — VK, Ozon, Авито, 2ГИС — идут напрямую |
| `NORU.list` | домены под отдельный прокси, используется только в `template.conf` |
| `AI.list` | AI-сервисы: ChatGPT, Claude, Gemini, Cursor. Только в `template.conf` |
| `YOUTUBE.list` | всё, что нужно для видео YouTube. Только в `template.conf` |
| `GOOGLE.list` | заготовка под отдельный прокси для Google. Пока не подключён ни к одному конфигу |

Строка с `#` в начале — выключенное правило. Так можно временно отключить домен, не удаляя его.

## Для продвинутых

[`template.conf`](https://raw.githubusercontent.com/zeklop/shadowrocket-configs/main/template.conf) — то же самое, но с группами прокси: `NORU` и `YOUTUBE` идут через NL, `AI` — через US. Имена ваших подключений в Shadowrocket должны совпадать с именами групп: `NL`, `US`, `RU`.
